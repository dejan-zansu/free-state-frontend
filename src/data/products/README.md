# Generated product data

Every file in this folder is generated by `3d-work/specs/export_frontend.py` from the research
spec files in `3d-work/specs/` (`<slug>.json`, `labels.json`, `i18n/<lang>.json` and
`site_manifest.json`). Do not hand edit anything here. Fix the source spec, label or
translation file and run the exporter again, otherwise the next export silently overwrites
the change.

`specs.<lang>.json` holds the localized spec tables keyed by product slug, one file per
language the app ships (de, en, fr, it). `catalog.json` is language independent and maps the
packed 3D models to their SKUs, spec slugs to database names and packages, and carries the
shared camera settings for model-viewer.
